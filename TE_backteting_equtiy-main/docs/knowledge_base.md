# QUANTLAB Knowledge Base Structure

The QUANTLAB knowledge base is organized across 10 structured domain directories:

```text
knowledge_base/
├── 01_backtesting/       # Fundamentals, OHLCV data, execution workflow
├── 02_strategies/        # SMA, EMA, RSI, MACD, Momentum strategies
├── 03_metrics/           # Sharpe, CAGR, Max Drawdown, Sortino, Win Rate
├── 04_execution/         # Transaction costs, commission, slippage models
├── 05_risk/              # Risk management, stop loss, position sizing
├── 06_biases/            # Look-ahead, survivorship, overfitting biases
├── 07_portfolio/         # Asset allocation, stock selection, rebalancing
├── 08_quantlab/          # System architecture & MADRID RAG pipeline
├── 09_ai/                # RAG overview, prompt design, grounding
└── 10_research/          # Quantitative methodology & research practices
```

Every document adheres to a strict standard format:
- Definition
- Why It Matters
- Core Concept
- How It Works
- Formula
- Example
- Common Mistakes
- Backtesting Considerations
- QUANTLAB Implementation
- Related Concepts
